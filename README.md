# ALVOS 🎯

Painel pessoal **offline-first** para transformar objetivos em ações e acompanhar progresso.

## O que já existe
- Dashboard “Hoje”
- Alvos com progresso de 0–100%
- Lista de ações com conclusão
- Projetos com progresso
- Persistência local com `localStorage`
- Interface responsiva para telemóvel
- Funciona sem API, sem base de dados e sem custos
- Tudo concentrado em `index.html`

## Como usar
Abra `index.html` no navegador. Os dados ficam guardados no dispositivo.

## Publicar no GitHub Pages
No GitHub: **Settings → Pages → Deploy from a branch → main → /(root)**.
